## 🚀 Projetos em destaque

### Admissão Digital — TOTVS Fluig

Desenvolvimento e sustentação de uma solução completa de admissão digital integrada ao TOTVS RM.

O projeto envolve:

- Portal público para candidatos
- Formulários de admissão por etapas
- Automação de workflows
- Upload e gerenciamento de documentos
- Organização de arquivos no GED
- Assinatura de documentos
- Geração de PDFs
- Validações de regras de negócio
- Cadastro de dependentes e benefícios
- Persistência de dados entre sessões
- Painéis de acompanhamento para o RH
- Integrações com TOTVS RM
- Notificações e templates de e-mail
- Responsividade para dispositivos móveis

### Edu 360 — Plataforma Educacional

Desenvolvimento de uma plataforma web voltada à comunicação e à gestão escolar.

Principais funcionalidades:

- Gestão de alunos, professores e diretores
- Organização de turmas e horários
- Visualização de notas e informações acadêmicas
- Comunicação entre escola, responsáveis e alunos
- Personalização da identidade visual da instituição
- Desenvolvimento de frontend e backend
- Integração com banco de dados
- Regras de negócio e funcionalidades administrativas
